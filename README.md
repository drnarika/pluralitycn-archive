# pluralitycn-archive

`wiki.pluralitycn.com`（多意识体中文百科，MediaWiki 1.43.11）的完整离线快照，抓取于 2026-10-16。

- 浏览站点：https://drnarika.github.io/pluralitycn-archive/
- 存档说明与取舍：[README.html](https://drnarika.github.io/pluralitycn-archive/README.html)
- 全文搜索：[search.html](https://drnarika.github.io/pluralitycn-archive/search.html)

`archive/` 内除渲染页面外，还包含 ZIM 归档（含全文索引，可用 Kiwix 打开）与维基源码全量导出
（368 个页面 / 1715 个历史版本的 dump XML + 全部图片原文件），附 SHA256 校验和。
